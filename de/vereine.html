Für Vereine

Flyer aufhängen.
Mitglieder sparen.

Euer Verein hängt den Kortscore-Flyer im Vereinshaus oder am Platz auf, und eure Mitglieder bekommen dafür einen Rabattcode für Kortscore Plus. Schreibt uns einfach, den Rest klären wir per Mail.

So geht's

  1. 01

    Anfragen

    Schreibt uns eine kurze Mail mit Vereinsname, Ort und Ansprechperson. Der Button unten füllt sie schon vor.

  2. 02

    Flyer aufhängen

    Druckt den Flyer auf A4 aus und hängt ihn gut sichtbar auf: im Vereinshaus, an der Pinnwand oder am Eingang zu den Plätzen.

  3. 03

    Code weitergeben

    Ihr bekommt einen eigenen Code für Kortscore Plus und gebt ihn an eure Mitglieder weiter, per Aushang, Newsletter oder Vereinsgruppe. Damit wird Plus in der App günstiger.

So lösen eure Mitglieder den Code ein

  1. Kortscore öffnen und den Kaufscreen von Kortscore Plus aufrufen, zum Beispiel in den Einstellungen unter Kortscore Plus freischalten.
  2. Auf Code einlösen tippen und den Code eures Vereins eingeben.
  3. Der günstigere Preis erscheint direkt am Kaufscreen. Gekauft wird wie gewohnt über den App Store oder Google Play.

Das funktioniert auf dem iPhone und auf Android gleich.

Was ist Kortscore Plus?

Kortscore selbst ist gratis: zählen am Handgelenk, Match-Historie und Live-Ticker, ohne Werbung und ohne Konto. Kortscore Plus ist ein einmaliger Kauf, kein Abo, und bringt erweiterte Statistiken, automatische Backups und den KI-Trainer, der die Matches analysiert. Mit eurem Code bekommen eure Mitglieder Plus günstiger.

Der Flyer

A4, eine Seite, mit QR-Code zum Download der App. Am besten in Farbe drucken, dann kommen Screens und Uhr gut rüber.

Häufige Fragen

Kostet das den Verein etwas?

Nein. Ihr hängt den Flyer auf, wir schicken den Rabattcode. Kortscore selbst ist für eure Mitglieder ohnehin gratis.

Wie hoch ist der Rabatt?

Das legen wir mit jedem Verein einzeln fest. Schreibt uns, wie viele Mitglieder ihr ungefähr habt, dann machen wir euch ein Angebot.

Funktioniert der Code auf iPhone und Android?

Ja. Der Code wird in der Kortscore-App am Kaufscreen von Kortscore Plus eingelöst, auf beiden Plattformen gleich.

Ist der Code unbegrenzt gültig?

Nicht unbedingt. Ein Code kann einen Gültigkeitszeitraum haben, den nennen wir euch zusammen mit dem Code.
